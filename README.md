# Jude Benz homepage

A lightweight GitHub Pages landing page linking to the existing music and audiovisual sites.

## Files
- `index.html` — page structure, metadata and Person structured data
- `style.css` — cinematic split-screen design and responsive behaviour
- `script.js` — small progressive-enhancement script
- `assets/` — replace the two photo placeholders with your own images

## Add your photographs
Add two landscape or portrait photographs (large, ideally 1800px wide or more):
- `assets/audiovisual.jpg` — Jude as music video director, ideally with a cinema camera
- `assets/music.jpg` — Jude as musician / singer

Use JPG or WebP, keep file sizes reasonably compressed, and preserve these exact filenames.
The supplied SVG illustrations are temporary placeholders; replace them with your photographs before launch.

## Check destination links
The page currently links to:
- https://jude-films.com/
- https://jude-music.com/

If your actual site URLs differ, update the `href` attributes in `index.html`.

## Publish on GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Do not add a `CNAME` file until the custom domain is ready to be connected.
